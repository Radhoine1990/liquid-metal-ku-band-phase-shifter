# Reconfigurable Liquid-Metal Ku-Band Phase Shifter

## Overview

This repository contains the implementation of an iterative Wave Concept Iterative Procedure (WCIP) method developed for the numerical analysis and design of a reconfigurable concentric ring phase shifter based on liquid metal for Ku-band applications.

The code was developed to investigate the electromagnetic behavior of the proposed structure and to evaluate its scattering parameters and phase-shifting characteristics for different liquid-metal configurations.

## Methodology

The numerical analysis is based on the iterative Wave Concept Iterative Procedure (WCIP) method.

The implemented approach includes:

* Definition of the phase-shifter geometry
* Definition of the liquid-metal configurations
* Electromagnetic initialization
* Iterative WCIP computation
* Convergence evaluation
* Extraction of the electromagnetic response
* Calculation and visualization of the phase-shifting characteristics
